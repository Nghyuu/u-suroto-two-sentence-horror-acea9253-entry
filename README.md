## What it does

Writes a two-sentence horror story to `/output/entry.txt` — a nursery speaker that learned its owner's voice a little too well.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later and `MAKEFUN_OUTPUT_DIR` set to the output directory.

## Entry

The story lives in `entry.txt` and is copied verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt` by `main.ts`.
